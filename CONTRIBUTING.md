# How to contribute

To contribute to this software, send PRs with your changes/additionas to the official repository 
at https://codebase.helmholtz.cloud/casus-datalad/datalad_automation/ with your name added at the end of 
one of the lists of names and institutions above.


# Agreement to re-licensing

All current contributors agree that CASUS/HZDR is allowed to re-license this software under an additional 
Open Source license which is more permissive.

In case you object to this, mentions it next to your name on one of the lists above.
